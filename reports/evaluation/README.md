# Evaluation Index

This directory contains evaluated summaries and plots, not raw runtime outputs.

## Layout

- `archive/`
  Historical or exploratory material that is no longer the primary citation target.
- `current/`
  Short dataset-level pointers to the canonical bundles that matter now.
- `index/`
  Dataset-specific index notes.
- `runbooks/`
  Human-readable execution notes.

Result bundles remain at the top level so existing paper references and figure paths do not break.
