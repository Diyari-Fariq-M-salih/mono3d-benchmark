# DA3-Streaming Pointer

This directory is intentionally not a second independent method root.

- `methods/depth_anything_3/upstream/da3_streaming/`

This top-level folder is kept only as a lightweight note so the repo surface stays readable.

Use these entry points instead:

- `bash scripts/setup_da3.sh`
- `bash scripts/install_da3_into_conda.sh da3stream`

- `bash scripts/run_da3_streaming.sh --image-dir /path/to/images`
